## 业务闭环

终止申请 → 权利依据核验 → 通知送达 → 未结义务盘点 → 数据与资产返还 → 最终结算 → 法务财务审批 → 相对方确认 → 归档。

## 核心门禁

- 终止权或双方合意依据、通知送达和未结义务盘点必须可验证。
- 数据返还/删除、最终应收应付、法务与财务批准均为强制条件。
- 经办与审批职责必须分离，通知、审批和结算证据链必须完整。
- 交付物验收、资产返还、税务、未决索赔和相对方确认形成复核事项。

## 接口与结果

`POST /api/enterprise/clm/termination-settlement`

返回 `TERMINATE`、`REVIEW` 或 `BLOCKED` 以及可解释的阻断原因、行动清单。电子签署、税务和支付系统仅预留适配器，项目不包含真实外部凭据。
